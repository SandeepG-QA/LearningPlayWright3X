# VS Code Keyboard Shortcuts & Commands

Essential shortcuts for everyday coding.

## General Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl + S` | Save file |
| `Ctrl + Z` | Undo |
| `Ctrl + Y` | Redo |
| `Ctrl + C` | Copy |
| `Ctrl + X` | Cut |
| `Ctrl + V` | Paste |
| `Ctrl + F` | Find in file |
| `Ctrl + H` | Find and Replace |
| `Ctrl + D` | Add selection to next find match (multi-cursor) |
| `Ctrl + Shift + L` | Select all occurrences of current selection |
| `Ctrl + /` | Toggle line comment |
| `Shift + Alt + F` | Format document |
| `F2` | Rename symbol |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl + P` | Quick Open (Go to File) |
| `Ctrl + Shift + P` | Command Palette |
| `Ctrl + G` | Go to Line |
| `Ctrl + Shift + O` | Go to Symbol in file |
| `Ctrl + B` | Toggle Sidebar |
| `Ctrl + \`` | Toggle Terminal |

## Line Operations

| Shortcut | Action |
|----------|--------|
| `Alt + ↑ / ↓` | Move line up/down |
| `Shift + Alt + ↑ / ↓` | Copy line up/down |
| `Ctrl + Shift + K` | Delete line |
| `Ctrl + Enter` | Insert line below |
| `Ctrl + Shift + Enter` | Insert line above |

## Multi-Cursor

| Shortcut | Action |
|----------|--------|
| `Alt + Click` | Add cursor at click position |
| `Ctrl + Alt + ↑ / ↓` | Add cursor above/below |
| `Ctrl + D` | Select next occurrence of selection |
| `Ctrl + Shift + L` | Select all occurrences |

## Debugging

| Shortcut | Action |
|----------|--------|
| `F5` | Start / Continue debugging |
| `F9` | Toggle breakpoint |
| `F10` | Step over |
| `F11` | Step into |
| `Shift + F11` | Step out |
| `Ctrl + Shift + D` | Show Debug view |

## Terminal

| Shortcut | Action |
|----------|--------|
| `Ctrl + \`` | Show integrated terminal |
| `Ctrl + Shift + \`` | Create new terminal |
| `Ctrl + Shift + 5` | Split terminal |

## Explorer & Views

| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + E` | Explorer view |
| `Ctrl + Shift + G` | Source Control (Git) view |
| `Ctrl + Shift + D` | Debug view |
| `Ctrl + Shift + X` | Extensions view |
| `Ctrl + Shift + F` | Search across files |
